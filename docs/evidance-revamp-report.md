## Not done, and why

1. **S8's live Deepgram run.** The one bounded paid call that would flip
   `streaming: true` for Deepgram was not made, so the platform does not
   offer managed streaming yet — by design, the flag is the promise and it
   has not been earned. The exact follow-up is in "Next".
2. **S11's fresh-environment proof.** A full `./launch.sh clean` →
   `./launch.sh start` cycle would delete the running database (with the
   live evaluation run behind S5's evidence) and both images; it was left
   to the owner rather than run mid-verification.
3. **The authenticated evaluations page was not click-through-verified on
   the live stack** — the browser session had expired and typing the
   password is out of bounds. The deployed bundle was instead proven to
   contain the new code, and the page is covered by 24 new component tests.
4. **Git hygiene failure (mine).** An `git add -A` during S8 swept
   subagent work-in-progress (S7's landing page, parts of S6/S10) into the
   S8 commit. Nothing was lost and everything is verified green, but three
   slices share one commit message. The practice stopped with that commit.
5. **ElevenLabs key regeneration** remains the owner's action: the key was
   pasted into a chat once; both `.env` files are gitignored so it never
   reached the repo, but the key should be rotated in the vendor dashboard.

## Where the revamp left the platform

* The API surface is pinned by a committed OpenAPI document; the UI renders
  only what the API returns, and says so when the API cannot be reached.
* Every capability and every limit carries its provenance; the platform
  refuses work it cannot honestly perform *before* spending money.
* Observability is on by default and has never broken a transcription.
* The one number this project can defend is the evaluation WER, and the
  console now shows the arithmetic behind it, token by token.
